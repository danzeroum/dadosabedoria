Spec de handoff

P1

Entrar (gov.br) — /entrar

Objetivo
Preparar o login OIDC gov.br, honesto sobre estar bloqueado. "O lugar já está preparado" (tom de AcoesOndeFoi.tsx).
Dados
Estático até o gate. Lê AUTH_HABILITADO (env, default false) de nova lib/auth.ts. Quando ligar, só essa flag muda.
Componentes do DS
Novo: .gov-botao (desabilitado) e .portao (idioma do .demo-aviso, role="note"). Reusa .legal.
Estados
Gated (mostrado, AUTH_HABILITADO=false) · habilitado (botão ativo → fluxo OIDC). Mesma tela, dois caminhos.
Invariantes
Login é só para alertas/consentimento — nunca condição para ver dado público. A tela reforça as 3 saídas sem conta. SSR puro: sem React Context, sem "use client" (PortaoAuth.tsx é server).
