Spec de handoff

P0

Boundary de erro — app/error.tsx

Objetivo
Capturar exceções de render/fetch (fonte fora do ar, falha de SSR) sem tela branca. Honesto: "o erro é nosso".
Dados
É "use client" (exigência do Next para error.tsx) e recebe { error, reset }. O botão chama reset(); aqui o mock usa location.reload().
Componentes do DS
Reusa .sistema-centro / .botao e o tom da classe .erro. Exibe o error.digest para suporte.
Estados
É o estado de erro. Único.
Invariantes & moldura honesta
Não responsabiliza o usuário; distingue "falha na consulta" de "dado perdido" (os dados não se perdem). Único arquivo que precisa de "use client" — quebra a cultura cliente-zero só onde o Next obriga.
Prioridade
P0 — robustez.
