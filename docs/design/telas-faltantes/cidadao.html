Spec de handoff

P2

Área do cidadão — /cidadao (+ /alertas, /consentimento)

Objetivo
Destino real do "Avise-me" e da gestão de consentimento. Hoje só um disclosure no OndeFoi — aqui ganha endereço.
Dados
sessaoAtual() de lib/auth.ts (mock → null até OIDC). Envolvida por novo PortaoAuth.tsx (server) que, sem sessão, renderiza o aviso.
Componentes do DS
Novo: .portao, .toggle-fake. Reusa .legal, .honesto. Subrotas /cidadao/alertas e /cidadao/consentimento seguem o mesmo molde.
Estados
Não autenticado (mostrado — controles inertes) · autenticado (toggles vivos, dados do perfil). PortaoAuth alterna entre os dois.
Invariantes
SSR puro, sem Context/"use client" (cultura cliente-zero). "Nada coletado ainda" é literal: a prévia não grava. Direitos LGPD (baixar/apagar) entram quando o login ligar.
Prioridade
P2 · gate OIDC
