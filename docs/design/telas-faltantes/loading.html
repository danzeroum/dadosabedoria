Spec de handoff

P1

Skeleton de carregamento — app/loading.tsx

Objetivo
Feedback durante o SSR force-dynamic (todo fetch é server-side e pode levar segundos). Reduz a percepção de lentidão sem mentir sobre o conteúdo.
Dados
Nenhum. loading.tsx renderiza enquanto o segmento resolve. Some sozinho quando a página real chega.
Componentes do DS
Novo (opcional): .skeleton / .sk-bloco / .sk-card. Espelha a grade do conteúdo que vai chegar (título + linhas + grade de cards).
Estados
É o estado de carregamento. Único.
Acessibilidade
aria-busy="true" no container + texto .sr-only "Carregando…". A animação respeita prefers-reduced-motion (sem brilho quando reduzido). Skeleton é decorativo: o leitor de tela ouve o aviso, não os blocos.
Prioridade
P1 — percepção de qualidade.
