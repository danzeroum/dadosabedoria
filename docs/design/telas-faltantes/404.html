P0

404 dedicado — app/not-found.tsx

Objetivo
notFound() é chamado em ~15 páginas de detalhe (município/produto sem dado). Hoje cai no 404 default do Next — quebra a percepção de qualidade.
Dados
Nenhum. Componente not-found.tsx (server). Mantém header/footer do layout.
Componentes do DS
Novo: .sistema-centro / .sistema-codigo / .botao. Links de saída para /produtos e /ivm.
Estados
É, em si, um estado (rota inexistente). Único.
Moldura honesta
Reaproveita a doutrina: "ausência não é veredito, é falta de cobertura" — o 404 não culpa o usuário nem finge que o dado existe. Reforça a saída via Perguntar.
Prioridade
P0 — robustez.
