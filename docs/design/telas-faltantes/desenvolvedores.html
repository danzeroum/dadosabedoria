API & Desenvolvedores

Tudo que o site mostra vem de uma API pública com proveniência. Os endpoints /v1/* de leitura são abertos e grátis; o tier profundo (lote e cota) usa chave. Toda resposta carrega a fonte.

Planos & preços · Painel de cota · Licenças por fonte

Base & autenticação

BASEhttps://api.dadosabedoria.org/v1

Endpoints de leitura são públicos. O tier profundo exige a chave no header — nunca em querystring nem no bundle do front.

# leitura pública — sem chave curl https://api.dadosabedoria.org/v1/fontes # tier profundo — chave no header curl https://api.dadosabedoria.org/v1/quota \ -H "Authorization: Bearer SUA_CHAVE"

Endpoints públicos

GET/v1/fontespúblico

Catálogo de fontes do acervo: domínios, cadência, atraso típico, licença e base legal.

curl https://api.dadosabedoria.org/v1/fontes
GET/v1/municipios/{codigo}público

Panorama de um município pelo código IBGE — todos os indicadores do acervo, com proveniência. O protegido vem como protegido (null + motivo), nunca como zero.

curl https://api.dadosabedoria.org/v1/municipios/3550308
GET/v1/mapa/ivmpúblico

IVM por UF como GeoJSON (FeatureCollection). Onde falta a malha geométrica, degrada para cartograma de tiles.

curl "https://api.dadosabedoria.org/v1/mapa/ivm?uf=35"

Tier profundo requer chave

GET/v1/quotachave

Consumo da sua chave na janela atual. Alimenta o Painel de cota.

curl https://api.dadosabedoria.org/v1/quota \ -H "Authorization: Bearer SUA_CHAVE" # 200 → { "limite": 1000, "usado": 342, "restante": 658, "janela": "hora", "reinicia_em": "2026-06-13T18:00:00Z" }
POST/v1/consultas-lotechave

Até 50 consultas por requisição — vários municípios × indicadores de uma vez. Cada item da resposta mantém sua própria proveniência e estado de supressão.

curl -X POST https://api.dadosabedoria.org/v1/consultas-lote \ -H "Authorization: Bearer SUA_CHAVE" \ -H "Content-Type: application/json" \ -d '{ "consultas": [ { "municipio": "3550308", "indicador": "ivm" }, { "municipio": "3304557", "indicador": "onde-foi" } ] }'
Contrato de honestidade da API. Todo número vem com fonte, periodo e lag. Dado suprimido por privacidade volta como null com motivo: "k_anon" — nunca como zero. Sem cobertura é motivo: "sem_cobertura". Sua aplicação deve distinguir os dois.

Limites, preços e o que cada plano libera estão em Planos & preços. As licenças de redistribuição variam por fonte — confira em Fontes & confiança.

Spec de handoff

P1

Docs da API — /desenvolvedores

Objetivo
Tornar a API legível: endpoints públicos + tier profundo (lote, cota), com curl copiável e o contrato de honestidade explícito.
Dados
Estático + buscarFontes() para a seção de licenças. Exemplos refletem POST /v1/consultas-lote e GET /v1/quota (espelhar tipos em api/app/profundo/modelos.py).
Componentes do DS
Novo: .endpoint / .metodo / .bloco-codigo. Reusa .honesto, .metodologia, .migalha.
Estados
Estático. A seção de licenças degrada se buscarFontes() retornar null.
Invariantes
Documentar que suprimido = null + motivo, nunca zero — a invariante de privacidade precisa estar no contrato da API, não só na UI. Chave sempre no header; o exemplo nunca a coloca em querystring.
Prioridade
P1 — monetização/adoção.
